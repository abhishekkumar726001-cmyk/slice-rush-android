# Slice Rush — Android Game

An original, lightweight slicing game inspired by the hold-to-slice arcade genre.

## Features

- Hold anywhere to raise the knife and slice colorful produce.
- Avoid metal obstacles; three mistakes end the run.
- Score, coins, lives, 5,000 progressive levels, particles, and screen shake.
- Completely ad-free: no ad SDK, no tracking SDK, and no internet permission.
- Portrait layout with no image assets or internet permission.

## Build APK

1. Open this folder in Android Studio (Ladybug or newer recommended).
2. Allow Gradle sync to finish.
3. Choose **Build > Build App Bundle(s) / APK(s) > Build APK(s)**.
4. The APK appears under `app/build/outputs/apk/debug/`.

Package: `com.alphaclasses.slicerush` · Minimum Android: 6.0 (API 23)
